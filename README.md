# Olivia Klintman Website

A minimalist, premium personal landing page.

## Structure
- `index.html`: Base structure with semantic tags and SEO optimization.
- `index.css`: Stylesheet featuring elegant typography, a subtle background glow, and responsive design.

## Features
- **Modern Typography**: Combines serif for elegance and sans-serif for readability.
- **Micro-Animations**: Smooth fade-in and slide-up effects.
- **Premium Palette**: Sophisticated dark mode with subtle gradients.
